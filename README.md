# רגע לנשום – גרסה ל־APK

האפליקציה בנויה עם Capacitor. התזכורות נשלחות כהתראות מקומיות של אנדרואיד, ולכן הן מגיעות גם כשהאפליקציה סגורה (כמו וואטסאפ), בלי שרת ובלי אינטרנט.

## מה יש בתיקייה
- `www/index.html` – האפליקציה כולה (עמוד ראשי + עמוד המדריך)
- `www/chime.mp3` – צליל העוגן
- `www/manifest.json` – שם, צבעים ותיאור
- `capacitor.config.json` – הגדרות ה־APK (מזהה: `com.regalinshom.app`)
- `setup-android.js` – מעתיק את הצליל לאנדרואיד ומוסיף הרשאות התראה

## בניית APK
דרוש: Node.js ו־Android Studio.

```
npm install
npm run setup
npm run open
```

ב־Android Studio: Build ← Build APK(s).

אחרי כל שינוי בקבצים שב־`www`, מריצים `npm run sync` ובונים מחדש.

## איך זה עובד
- לחיצה על "התראות ברקע" מבקשת הרשאת התראות. באנדרואיד 12 ומעלה ייפתח גם מסך "התראות ותזכורות" כדי לאשר שעונים מדויקים.
- כשהתזכורות פעילות וההתראות ברקע מאושרות, כל שעות התזכורת נקבעות במכשיר וחוזרות כל יום.
- כשהאפליקציה פתוחה ללא התראות ברקע, הצליל מושמע מתוך האפליקציה לפי מחוון "עוצמת שמע".
- כשהאפליקציה סגורה, עוצמת הצליל נקבעת לפי עוצמת ההתראות של המכשיר. אנדרואיד לא מאפשר לאפליקציה לקבוע עוצמה להתראה.
- הערוץ נקרא "תזכורות נשימה". אם מחליפים את קובץ הצליל אחרי התקנה, צריך להסיר ולהתקין מחדש את האפליקציה, כי אנדרואיד שומר את צליל הערוץ.

## אם מתעלמים ממה שכאן
אם ממירים את `www` ל־APK בכלי אחר (לא Capacitor), האפליקציה תעבוד, אבל התראות כשהאפליקציה סגורה לא יפעלו.
